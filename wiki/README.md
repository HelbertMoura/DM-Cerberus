# 📚 Wiki & Conhecimento Cross-Produto

Esta pasta armazena artigos, notas técnicas e padrões de engenharia compartilhados entre múltiplos projetos.

---

## 🧭 Organização

- **Artigos Técnicos:** Documentos conceituais sobre infraestrutura, padrões de código e algoritmos.
- **Protocolos de Agentes:** Diretrizes operacionais para cooperação entre agentes de IA.

Cada documento deve utilizar frontmatter YAML com `titulo`, `tags`, `atualizado` e `status`.
