# 📦 archive/historical — Diretório de Arquivo Histórico

> **Política:** Apenas arquivos com aprovação do PO são movidos para cá. Marcar com banner `SUPERSEDED — ver <canônico novo>` antes de mover. Preservar leitura histórica. Não deletar.

---

## Estado atual (26/08/2026)

Esta pasta foi **criada** como parte da evolução do DM-CEREBRO para Second Brain multi-projeto v1, mas **nenhum arquivo foi movido para ela nesta rodada**. Ela é um **marker** — uma posição reservada para o que for aprovado.

**O que PERTENCE a `archive/historical/` (quando aprovado):**

- ADRs ou arquivos `decisions.md` substituídos por ADR mais novo (com link ao superseding).
- Arquivos de status/relatório de projetos descontinuados (ex.: `hub-remote-ide`).
- Versões antigas de templates ou schemas de governança.
- Qualquer arquivo que perca a função canônica mas precise ser preservado para rastreabilidade.

---

## Política de Movimento

1. **NUNCA** mover arquivo sem aprovação explícita do PO.
2. **SEMPRE** marcar com banner `SUPERSEDED — ver <canônico novo>` antes de mover.
3. **SEMPRE** criar um link/referência no novo local canônico.
4. **NUNCA** deletar. O arquivo vai para `archive/historical/`, não para a lixeira.
5. **PRESERVAR** a leitura histórica — manter o conteúdo original intacto.
